# SECURITY — تدقيق أمني (SECURITY AUDIT)

**النطاق:** إصلاحات جلسة 2026-11-12 + الوضع القائم (تقاطع مع `docs/SECURITY_REVIEW_27.md`).

---

## 1. سطح الهجوم الحالي

| السطح | الحماية | الدليل |
|---|---|---|
| `/api/ai` | حد 8 طلبات/دقيقة لكل IP + حد حجم 8 KB | اختبار محلي أعاد `429` بعد 3 طلبات في نافذة واحدة (حد أدنى مشترك) |
| مدخلات AI | `parseAiRequest`: إزالة أحرف التحكم، رفض الطويل (413) لا اقتطاعه | `lib/security/validate.test.ts` (6 اختبارات) |
| حقن الموجّه | السؤال معزول في `<question>` + تعليمات «بيانات لا أوامر» | `app/api/ai/route.ts` |
| مخرجات المزوّد | تحقق نوعي لكل حقل قبل العرض | `route.ts` (`str`/`arr`) |
| XSS | React escaping + CSP | ترويسات CSP في `next.config`/middleware |
| Supabase RLS | 33 جدولًا + إصلاح عودية `0015` | `supabase/migrations/0015_*` |
| تقارير الأخطاء | insert-only + حد 5/دقيقة | `docs/SECURITY_REVIEW_27.md` |

## 2. أثر التغييرات الجديدة

| التغيير | الأثر الأمني |
|---|---|
| دمج `STRUCTURED_DOCUMENTS` في الاسترجاع | صفر: بيانات ثابتة داخلية، لا مدخلات مستخدم |
| قراءة الملفات في `/legal/[slug]` | صفر: المسار من سجل ثابت، وتُتخطى المصادر المهيكلة (`file: ""`) |
| `matchProcedure` | صفر: بيانات ثابتة |
| إصلاح النصوص | صفر: تعديل محتوى، لا منطق تنفيذ |
| سكربتات Node جديدة | تعمل محليًا فقط، ليست ضمن الحزمة المنشورة |

**لم يُضف أي مسار API أو جدول أو متغير بيئة.**

## 3. الأسرار

- لا `service_role` في أي `NEXT_PUBLIC_*`.
- المفتاح العام المستخدم: `sb_publishable_…` (آمن للعميل).
- `AI_PROVIDER_API_KEY` يُقرأ من بيئة الخادم فقط.

## 4. عوائق قائمة

| # | البند | الخطورة |
|---|---|---|
| 1 | لا WAF/قواعد Cloudflare مخصصة موثّقة في المستودع | متوسطة |
| 2 | لا تدقيق تبعيات آلي (Dependabot/`npm audit` في CI) | منخفضة |
| 3 | محتوى قانوني غير مراجَع بشريًا (خطر مهني لا أمني) | عالية قانونيًا |

## 5. نتيجة التدقيق

لا ثغرة جديدة أُدخلت بهذه الجلسة. الحماية القائمة (CSP، RLS، rate limit، تحقق المدخلات) لم تُضعَف.
