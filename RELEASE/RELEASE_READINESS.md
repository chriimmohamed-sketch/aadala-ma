## 4. أمر النشر (عند الموافقة)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\deploy.ps1
```

ثم التحقق:
```bash
curl -s https://aadala-ma.cheraimmohamed20.workers.dev/ar -o /dev/null -w "%{http_code}\n"
curl -s -X POST https://aadala-ma.cheraimmohamed20.workers.dev/api/ai \
  -H "Content-Type: application/json" \
  -d '{"question":"مدة الطعن بالاستئناف","locale":"ar"}'
```

**تحذير تشغيلي:** الاستجابات تحمل `s-maxage=31536000`؛ بعد النشر يلزم تحديث قسري (Ctrl+Shift+R) للتحقق من الواجهة.
