# AADALA.MA — مركز الذكاء التشريعي المغربي

## الغرض والنطاق

هذا المستند يحدد الأساس التشغيلي لمركز يرصد المصادر القانونية المغربية، ويجمع الإصدارات، ويتحقق من بياناتها، ويتابع التعديلات، ويغذي الموسوعة والمساعد القانوني بعد المراجعة. هذه المرحلة تؤسس سجل المصادر وسياسة الإثبات؛ ولا تدعي تشغيل مراقبة آلية أو إتمام التحقق من قاعدة البيانات الحية.

## مبدأ الإثبات القانوني

ترتيب الحجية التشغيلية داخل المنصة:

1. الجريدة الرسمية الصادرة عن الأمانة العامة للحكومة: دليل النشر الرسمي.
2. البوابات الحكومية والمؤسساتية: للاكتشاف والحصول على نسخ ومعلومات مساعدة، مع مطابقة النص المنشور عند الحاجة.
3. مصادر الاجتهاد غير الحكومية: للاكتشاف فقط إلى أن يُتحقق من القرار وبياناته ومصدره.
4. الأبحاث والشروح: مواد تفسيرية لا تُعرض كنصوص تشريعية أو أحكام.

لا يكفي وجود رابط أو نسخة PDF لإثبات أن النص محين أو نافذ. يجب توثيق رقم النص، عنوانه، نوعه، رقم الجريدة الرسمية، تاريخ النشر، تاريخ الدخول حيز التنفيذ إن ثبت، النص المعدِّل، نطاق التعديل، ومصدر كل معلومة.

## ملفات الأساس المضافة

- `data/legal-source-registry.json`: سجل المصادر ونطاقها ودرجة سلطتها والاستخدام المسموح.
- `scripts/validate-legal-source-registry.mjs`: تحقق محلي من بنية السجل وتفرّد المعرفات وصحة الروابط والسياسات.
- `npm run legal:sources:check`: بوابة تحقق لا تتصل بالمواقع ولا تنزّل محتوى.

## سير العمل المستهدف

### A. الرصد والاكتشاف
- مراقبة صفحات الاكتشاف العامة في سجل المصادر.
- حفظ عنوان المصدر والرابط وتاريخ الالتقاط ووقت الالتقاط وبصمة SHA-256.
- الاحتفاظ بالنسخة السابقة وعدم استبدالها.
- تسجيل حالات الحجب أو تغير بنية الصفحة كحالات فشل، لا كغياب للمستجدات.

### B. الاستلام والتوثيق
لكل ملف مستلم، خزّن:
- source_id وcanonical_url وretrieved_at.
- اسم الملف ونوع MIME والحجم وSHA-256.
- رقم الجريدة الرسمية وتاريخها إذا توفرا.
- لغة الوثيقة ونوعها ورقمها وتاريخ إصدارها.
- حالة الاستخراج وجودته وأداة الاستخراج وإصدارها.

### C. استخراج ومقارنة
- استخراج النص مع الاحتفاظ بصفحات PDF وترقيمها.
- مقارنة النص المستخرج بالملف الأصلي، مع كشف الصفحات الفارغة أو المكررة أو الناقصة.
- تقسيم المحتوى إلى مواد وفصول مع حفظ موضع كل مقطع في الصفحة.
- عدم إصلاح OCR بصمت؛ كل تصحيح تحريري يسجل منفصلاً ويراجع بشرياً.

### D. تحليل الأثر التشريعي
كل تعديل يجب أن يرتبط بالنص المعدِّل والنص المتأثر والمادة أو الفقرة المتأثرة، مع:
- نوع العملية: تعديل، تتميم، نسخ كلي، نسخ جزئي، تصحيح، تفسير.
- تاريخ النشر.
- تاريخ النفاذ كما يثبته النص أو مقتضى رسمي.
- النطاق الدقيق للتعديل.
- دليل المصدر والصفحة/المادة.
- حالة المراجعة.

لا تستنتج النفاذ من تاريخ النشر تلقائياً؛ افحص مقتضى النفاذ والقواعد الانتقالية وأي تاريخ مؤجل.

### E. المراجعة والنشر
حالات الوثيقة:
- discovered
- downloaded
- extracted
- quality_checked
- legal_review
- approved
- published
- rejected
- superseded

لا تنتقل إلى published إلا بعد:
1. التحقق من المصدر.
2. اكتمال بيانات التعريف.
3. فحص جودة النص المستخرج.
4. مراجعة التعديلات والنفاذ.
5. موافقة مراجع مخول.
6. الاحتفاظ بالنسخة الأصلية وسجل التغييرات.

## قواعد خاصة بالمساعد القانوني

- لا يستخدم المستندات غير المعتمدة كأساس قطعي لجواب قانوني.
- يعرض حالة المصدر وتاريخ آخر تحقق.
- يفرق بين النص الرسمي والنسخة المرجعية والشرح.
- عند اختلاف نسختين، يوقف الجزم ويعرض التعارض للمراجع.
- لا يستنتج أن المادة غير موجودة لمجرد فشل استخراجها.
- يجب أن يحدد البحث نوع التشريع/المصدر قبل مطابقة رقم المادة لتفادي خلط مواد متشابهة الرقم.

## أولويات التنفيذ التالية

1. ربط السجل بواجهة الإدارة مع حالات مراجعة واضحة.
2. إضافة نموذج موحد لبيانات الوثيقة والإصدار والمصدر.
3. بناء موصلات اكتشاف منفصلة لكل مصدر بعد فحص شروط الاستخدام والاستقرار التقني.
4. بناء طابور مراجعة OCR وجودة الاستخراج، بدءاً بالمصادر ذات الجودة المنخفضة.
5. إنشاء سجل تعديلات زمني مع توثيق دليل كل علاقة.
6. إضافة اختبارات RAG تمنع الاستشهاد من مصادر غير معتمدة.
7. إضافة اختبارات صلاحيات ومراجعة بشرية قبل النشر.

## حدود هذه المرحلة

- لا توجد عملية scraping أو polling دورية مفعّلة في هذا التغيير.
- لا يتم تنزيل أو إعادة توزيع ملفات المصادر تلقائياً.
- لا توجد تغييرات على قاعدة Supabase أو بيانات الإنتاج.
- لا يُعلن عن صحة أو نفاذ أي قانون جديد بمجرد ظهوره في صفحة اكتشاف.
- لا تُعتبر الروابط غير الحكومية مصدراً رسمياً.

## التحقق المحلي

شغّل:

```bash
npm run legal:sources:check
```

هذا الاختبار يتحقق من سلامة ملف السجل فقط؛ ولا يثبت إمكانية الوصول إلى المواقع أو صحة المحتوى القانوني.
