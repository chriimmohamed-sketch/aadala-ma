## 4. منهجية التحقق (مكرَّرة في كل دفعة)

لكل وثيقة:
1. `HEAD` على الرابط الرسمي → يجب أن يعيد `200` + `Content-Type: application/pdf`
2. `GET` → تنزيل البايتات الكاملة
3. `sha256` على البايتات → بصمة 16 محرف
4. `pypdf` → قراءة عدد الصفحات واستخراج النص
5. عدّ المحارف غير الفاصلة → **معيار الجودة**
6. تحديث `CONSOLIDATED_LAWS.csv`:
   - `verification_level` = `A — HEAD-verified + extracted`
   - `accessed_at` = الطابع الزمني الفعلي
   - `status` = `HEAD-verified + extracted`
7. حفظ PDF في `docs/legal-intelligence/raw/{id}.pdf` (gitignored — ثنائيات كبيرة)

**حدّ أدنى للجودة المستخدمة:** كل وثيقة بها > 2,000 محرف غير فاصل. أي ملف تحت ذلك
يُراجَع يدويًا (BO-7530 مثلًا: 3,339 محرف — نشرة اتفاقيات، نصها مضغوط، **ليس خطأ**).
