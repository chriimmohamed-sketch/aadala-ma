# الاجتهاد القضائي (0011) — مخطط فقط

## المايغريشن
`supabase/migrations/0011_case_law.sql` (تطبيق يدوي بعد `0001-0010` في SQL Editor).

جدول `case_law` — قراءة المنشور فقط للعموم، إدارة للمراجعين/المحررين/المسؤولين.

## لم يُزرع قرار
المدوّنة الحالية فارغة (`data/jurisprudence.ts: []`) بقصد — لا قرارات مختلَقة. أضف فقط قرارات من مصادر رسمية مُتحقق منها (`source_ref` + `status='published'`).

## المؤجل
`embedding vector(1536)` + فهرس `ivfflat` + بحث دلالي — يتطلب `pgvector` + مزوّد تضمين معتمدًا + تقييم، والاسترجاع الحالي TF-IDF يكفي.
