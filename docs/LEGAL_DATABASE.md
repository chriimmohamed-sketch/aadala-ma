## 1ب. «مهام النيابة العامة» (مصدر جديد)
- الملف: `مهام النيابة العامة.pdf` (38 صفحة، مقتطف يبدأ عند الصفحة 29).
- النص: `public/legal/niaba-ama-maham.txt` (63,418 حرفًا).
- **التصنيف: دليل إرشادي من وزارة العدل — للمرجعية فقط.** يشرح أدوار النيابة العامة لدى المحاكم الابتدائية (الدعوى العمومية، الحراسة النظرية، التفتيش، التنقيط، البطائق، تسليم المجرمين، رد الاعتبار...)، والمحاكم التجارية، ومحكمة الاستئناف، ومحكمة النقض (الطعن بالنقض لفائدة القانون، الإحالة، المساعدة القضائية...).
- لا يُعامل كنص تشريعي: عند التعارض، النص التشريعي (ق.م.ج، ق.م.م، التنظيم القضائي...) هو الحاكم.

## 2. تنبيه مهم: 39.08 ≠ 09.08
- **39.08** = مدونة الحقوق العينية (المرفوعة).
- **09.08** = القانون المتعلق بحماية المعطيات الشخصية + اللجنة الوطنية لمراقبة حماية المعطيات الشخصية (CNDP) — **غير مرفوع**.
- صفحة `/ar/privacy` تشير إلى 09.08 بوصفه التزامًا تصميميًا لاحقًا، لا نصًا مدمجًا. ارفع نصه نصيًا إن أردته في الموسوعة.

## 3. البنية
```
public/legal/*.txt        النصوص المستخرجة (7) — المصدر التشغيلي للبحث والذكاء الاصطناعي
data/legal-database.ts     سجل الوصف الكامل: الرقم، التواريخ (صدور/نشر)، المصدر، النسخة،
                          التعديلات، الإلغاء، النفاذ، عدد المواد، SHA-256، الحجم
data/legal-sources.ts      صلة عرض فقط (slug/title/type/file)
scripts/ingest-pdfs.mjs    npm run legal:ingest — تحقق + عدّ مواد + SHA-256 + تقرير
docs/legal-ingestion-report.md   الناتج
supabase/schema.sql        PostgreSQL: laws/sections/articles(+ ... )
supabase/seed-legal.sql    بذرة بيانات المصادر (metadata فقط — لا نص مخترع)
```

## 4. التشغيل
```bash
npm run legal:ingest   # تحقق + تحديث data/legal-database.ts + تقرير
```

## 5. التطبيق في الموقع
- صفحة `/ar/legal` تعرض 7 مصادر من `legalSources` + قسم "قاعدة البيانات" من `legalDatabase`.
- بحث ومحرك AADALA AI يبقيان على النصوص المستخرجة (`Retrieval` و`unverifiedCitations` يعلمان النصوص غير المطابقة).

## 6. لا محتوى مخترع
كل الأرقام من ملفات مستخرجة، والتواريخ من صفحات الغرض/التصدير للـ PDF. عند تضارب نص مع الجريدة الرسمية فالأمر للجريدة (نص المصادر نفسها يقول ذلك).
