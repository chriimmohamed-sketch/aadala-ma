# ENGINE — محرك البحث القانوني (LEGAL SEARCH ENGINE)

**الملف:** `lib/ai-assistant/retrieval.ts` · **المستهلك:** `POST /api/ai`
**النوع:** استرجاع معجمي (lexical) بوزن IDF — لا embeddings.

---

## 1. المصادر الموحّدة

عند أول استدعاء (`load()`)، يُبنى فهرس واحد في الذاكرة من:

1. `data/legal-index.json` — 732 مقطعًا من 6 نصوص مستخرجة.
2. `STRUCTURED_DOCUMENTS` في `lib/legal-data/` — 9 قوانين، 127 مادة، عبر `flattenArticles`.

كل مُدخل: `{ slug, title, excerpt, location, n?, verified?, tokens }`.

**إضافي بحت:** لم يُعدَّل `legal-index.json` عند الدمج؛ البيانات المهيكلة تُضاف في وقت التحميل.

## 2. المعالجة اللغوية

| الخطوة | التفصيل |
|---|---|
| تطبيع | إزالة التشكيل والتطويل؛ أ/إ/آ/ٱ→ا؛ ى→ي؛ ئ→ي؛ ؤ→و؛ ة→ه |
| كلمات وظيفية | قائمة `STOPWORDS` تشمل أدوات الاستفهام والجار والمجرور، وأسماء الإطار («أنواع»، «المغرب») |
| السوابق | `و ف ب ك ل` + أداة التعريف: `بالاستئناف`→`استئناف`، `وشروطها`→`شروطها`، `للمحكمة`→`محكمة` |
| اللواحق | `هما هم ها ات ون ين ي ه` عند بقاء ≥3 أحرف: `شروطها`→`شروط`، `شهادة`→`شهاد` |
| مرادفات استرجاع | خريطة صغيرة موثقة: `طلاق↔تطليق`، `مدة↔أجل`، `كراء↔إيجار` — **أداة بحث لا ادعاء قانوني** |

> المرادفات لا تُغيّر النص المعروض؛ تُوسّع المطابقة فقط.

## 3. الترتيب

لكل كلمة في السؤال: `weight = log(1 + N / df)`، حيث `df` = عدد المُدخلات التي تحتوي الكلمة (أو أيًّا من صيغها).

- `coverage = Σ أوزان الكلمات المطابقة / Σ أوزان كل كلمات السؤال`
- يُقبل المقطع فقط إذا: `coverage ≥ 0.4` **و** (تطابقت **أندر كلمة** في السؤال أو `coverage ≥ 0.55`).
- عند غياب كلمة نادرة (سؤال بكلمات شائعة): العتبة ترتفع إلى `0.6`.

**الهدف:** كلمة عامة واحدة لا تكفي لجلب قانون من فرع آخر.

## 4. الواجهات المصدَّرة

| الدالة | الاستخدام |
|---|---|
| `retrieve(question, topK=5)` | ترتيب المقاطع |
| `lookupArticles(question)` | بحث مباشر: «الفصل 230» / «المادة 12» → `score=1000` |
| `retrieveWithRefs(question, topK=6)` | دمج البحث المباشر + الترتيب + إزالة التكرار |
| `retrievalQuality(question, chunks)` | high/medium/low/insufficient_sources |
| `unverifiedCitations(text, chunks)` | أرقام مواد غير موجودة في المصادر |
| `suggestNearest(question)` | أقرب مواضيع عند غياب أي مقطع (ليست أدلة) |
| `tokenize` / `normalize` | متاحة للاختبارات |

## 5. القيود المقيسة

- **«شهادة صحة عقد البيع»** تعيد مادة عن شهادة الرهن: تضافر معجمي (`شهادة` + `عقد`) بلا فهم للتركيب الإضافي. النتيجة `low` + تنبيه.
- **النصوص السبعة غير المفهرسة** غير متاحة للمحرك (جودة استخراج غير كافية).
- **لا تعلّم آلي:** لا يتعلم من نقرات أو تصحيحات.
