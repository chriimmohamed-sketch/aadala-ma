# Dev Master Installer

حزمة موحدة لتحميل مستودعات GitHub المذكورة وتثبيت/تهيئة الأدوات المفتوحة المصدر.

## التشغيل

### Linux / macOS
```bash
chmod +x install.sh
./install.sh
```

### Windows PowerShell
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install.ps1
```

## ما الذي تنفذه الحزمة؟
- تنشئ `Dev_Master_Folder` والمجلدات الأربعة المطلوبة.
- تحمّل مستودعات المشاريع حسب المستوى.
- تحمّل مستودعات الأدوات التسعة.
- تتعامل مع روابط GitHub من نوع `/tree/branch` بتحديد الفرع عند الاستنساخ.
- تتحقق من وجود Git وDocker وPython وNode.js.
- تثبّت yt-dlp وWhisper عبر pip عند توفر Python، وتحاول تثبيت Ollama بالطريقة المناسبة للنظام.
- تعرض إرشادات إعداد Docker للأدوات التي تتطلب إعداداً إضافياً.

## تنبيه حول العدد
القائمة التي زودتني بها تحتوي على **73 رابط مشروع** فقط، وليس 100:
- 30 مبتدئاً
- 20 متوسطاً
- 23 متقدماً

بالإضافة إلى 9 مستودعات للأدوات المفتوحة المصدر. لم تتم إضافة مشاريع غير مذكورة أو اختلاق روابط لاستكمال العدد.

## ملاحظات تشغيلية
- تحتاج عملية التحميل إلى اتصال بالإنترنت وGit ومساحة تخزين كافية.
- قد تفشل بعض المستودعات إذا حُذفت أو أصبحت خاصة أو تغيّر اسمها.
- وجود Docker/Python/Node.js لا يعني أن كل خدمة تم تشغيلها أو إعدادها؛ بعض الأدوات تحتاج متغيرات بيئة وقواعد بيانات وأسراراً ونطاقاً.
- لا تُشغّل الحزمة خدمات Docker تلقائياً، ولا تفتح منافذ أو تنشئ حسابات افتراضية.
- راجع ملفات README الرسمية لكل مشروع قبل تثبيته أو تشغيله.
